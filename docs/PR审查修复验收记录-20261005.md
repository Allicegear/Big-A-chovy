## 本轮 P1 补修（2026-10-05）

### 旧 head 反例与修复

- 公告反例使用合成 payload：`data.total=0` 与 `data.total_hits=8` 同层冲突，以及外层 `total_hits=8` 与内层 `total_hits=0` 冲突。干净导出 `898c60f` 上的新增测试证明两者都会返回空列表、写 `clean` 缓存；实际筛选池/状态因此也错误放行。磁盘缓存测试同样确认会写入 `clean`。
